KimiPets - Hệ thống quản lý và bán hàng thú cưng
1. Giới thiệu

KimiPets là một hệ thống website được xây dựng nhằm hỗ trợ việc quản lý và kinh doanh các sản phẩm, dịch vụ dành cho thú cưng. Hệ thống giúp người dùng dễ dàng tìm kiếm, lựa chọn và mua sắm các sản phẩm như thức ăn, thuốc và phụ kiện cho thú cưng, đồng thời hỗ trợ quản lý thông tin khách hàng và đơn hàng một cách hiệu quả.

Bên cạnh đó, hệ thống còn tích hợp các chức năng hỗ trợ như chatbox AI và đặt lịch dịch vụ, góp phần nâng cao trải nghiệm người dùng.

2. Mục tiêu hệ thống

Xây dựng một nền tảng bán hàng trực tuyến thân thiện và dễ sử dụng

Hỗ trợ quản lý sản phẩm, khách hàng và đơn hàng một cách khoa học

Tối ưu hóa quy trình mua sắm cho người dùng

Tạo nền tảng mở rộng cho các dịch vụ thú cưng trong tương lai

3. Chức năng chính
3.1 Đối với người dùng

Đăng ký và đăng nhập tài khoản.
  Xem danh sách sản phẩm và thông tin chi tiết sản phẩm.
  Tìm kiếm sản phẩm phù hợp với nhu cầu.
  Thêm sản phẩm vào giỏ hàng và tiến hành đặt hàng.
  Thanh toán trực tuyến cho đơn hàng.
  Đặt lịch dịch vụ spa cho thú cưng.
  Sử dụng chatbox AI để được tư vấn và gợi ý sản phẩm.
  Theo dõi đơn hàng và lịch đặt dịch vụ.

3.2 Đối với quản trị viên

Bảng điều khiển tổng quan
Quản lý danh mục 
Quản lý hình ảnh 
Quản lý đơn hàng 
Quản lý tài khoản
Quản lý lịch spa 

4. Công nghệ sử dụng

Backend: ASP.NET MVC

Database: SQL Server

Frontend: HTML, CSS, JavaScript

Triển khai: SOMEE

5. Cài đặt và chạy dự án
5.1 Yêu cầu

Visual Studio

SQL Server

.NET Framework phù hợp

5.2 Các bước thực hiện

Clone repository về máy

Mở project bằng Visual Studio

Khởi tạo database trong SQL Server

Chạy project

6. Triển khai
